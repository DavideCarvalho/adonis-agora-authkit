New **experimental** package: a reference Personal Agent (client side) for the Personal Agent Protocol (Poppy) **Draft 0.1**, as a library and a `poppy-agent` CLI: discovery, agent identity (`private_key_jwt`), DPoP-bound Sessions, Direct/Device/Mediated sign-in, Account Tokens and revocation, OpenAPI and MCP calls, conversations over SSE, browser sessions and an LLM "ask" mode. The spec is still in development; this package tracks it and will change, possibly in breaking ways, as the spec evolves.
